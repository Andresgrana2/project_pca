# Aprobación de ejecuciones

Antes de ejecutar cualquier comando, script, prueba, compilación, aplicación u otra operación ejecutable en este proyecto, se debe obtener la aprobación explícita de Andrés para esa ejecución.

Sin esa aprobación, no se debe ejecutar la operación. Se debe indicar qué se desea ejecutar y esperar la autorización de Andrés.
